# むしカート

庭園サーキットを走る、オリジナルの3Dむしレースです。iPhoneのSafari向けです。

任天堂のキャラや名称は使っていません。

## 公開URL

- ゲーム: https://oz-ai-create.github.io/mushi-kart/
- ソース: https://github.com/OZ-ai-create/mushi-kart

Safariで開いて、共有 → **ホーム画面に追加** すると全画面で遊べます。公開URLはHTTPSなので、傾けてハンドルも使えます。

## 開発

```bash
npm install
npm run dev
```
