あそびかた

  • タイムアタックは一人で記録を狙うよ。どのコースも3周でゴール
  • タイトルのステージ変更で、ガーデン・海・火山を切り替えられるよ。BGMもコースに合わせて変わるよ。自己ベストもコースごと
  • コース上にはむしの天敵が決まった動きでいるよ。ガーデンは鳥、海は魚、火山は炎。近いと画面に出るよ。当たると止まってしまう
  • 傾けてハンドルは、HTTPSで開いたiPhoneで使えるよ
  • CPU対戦は3台のむしと順位を争うよ
  • レース前にボディとタイヤを選ぶと、重さ・曲がりやすさ・スピード・加速が変わるよ
  • カートはじどうで走るよ
  • 画面の左がわを指で左右にすべらせて曲がる
  • ドリフトは曲がりながら長押し。火花が3段階に光ったら離すと加速するよ。カウントのゴーで押しているとロケットスタートになるよ
  • 金色のハチの巣に当たるとアイテムが出る。最大2個持てるよ。スロットをタップして使うアイテムを選んでね
  • はっぱは後ろからの攻撃が来ると自動で盾になるよ。温存するか今使うか考えよう
  • コースには近道・ジャンプ・潮流・溶岩があるよ。速いけど危ない道と、安全な道を選ぼう
  • 3周目は最終ラップ。障害物が速くなってBGMも変わるよ
  • CPU対戦はタイトルでやさしい／ふつう／きびしいを選べるよ
  • むしごとに必殺技が1つあるよ。レース中に1回だけ使える。右の必殺ボタン、またはキーボードの E
  • キーボードなら ← → でハンドル、Shift でドリフト、Space でアイテム、E で必殺

必殺技

  • 🪲 ヘラクレス　角突き … 近くの相手を角で蹴散らす
  • 🐞 テントウ　てんとう舞い … コースの真ん中へ戻って、しばらく曲がりやすくなる
  • 🐝 ミツバチ　みつばちジェット … 一気に加速して、うしろにハチミツを残す
  • 🦗 キリギリス　大ジャンプ … 大きく跳んで天敵を飛び越える
  • 🗡️ カマキリ　かまいたち … 前方に斬撃を飛ばして相手をスピンさせる
  • 🟤 クワガタ　大あごブースト … 短時間、大幅加速しながら体当たりで弾く
  • 🦋 チョウ　フラワーターン … 一定時間、曲がりとドリフトが強くなる
  • 🩵 トンボ　超加速 … 一気に最高速度まで加速する
  • 🦘 バッタ　ハイジャンプ … 大ジャンプして障害物や近道を飛び越える
  • 🐜 アリ　アリ軍団 … 周囲にアリを出して相手を妨害する
  • 📢 セミ　爆音ダッシュ … 加速しつつ近くの相手をひるませる
  • 🌟 ホタル　光のベール … 一定時間、アイテム攻撃を無効化する

  • 🌰 どんぐり … 前に投げて当たったカートを止める
